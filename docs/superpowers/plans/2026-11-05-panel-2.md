# Panel 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `/admin` into a persistent, real-time management console that browses exported iCloud data, verifies it against live iCloud, OCRs images for search, and classifies BIP39 seed phrases.

**Architecture:** The web process gains a cookie-protected read API over `export/<email>/` and reads `server/data/items.json` read-only to map accounts. The socket process adds two job types, `verify` and `scan`; the Python worker enumerates live iCloud for verification and runs RapidOCR + BIP39 detection for scanning. React tabs render the export and the scan artefacts; all browsing/search results show the original image, never the OCR text as the result.

**Tech Stack:** Node 24 / Express / Socket.IO / React 19 / Tailwind, Python 3.12 + pyicloud + RapidOCR (onnxruntime) + Pillow.

**Spec:** `docs/superpowers/specs/2026-11-05-panel-design.md`

## Global Constraints

- Do not change the Apple front-end pages; pixel tests must stay within their current thresholds.
- The web process must never write `server/data/items.json` or call pyicloud.
- Every export path goes through `resolveWithin(root, rel)`; traversal must fail with 404.
- Panel auth: `HttpOnly`, `SameSite=Lax`, `Path=/`, 7-day HMAC cookie; password accepted as a fallback on the socket only.
- Search results display images/files; OCR text is never the result row (used for matching only).
- Seed tiers: 5–7 minimum, 8–11 medium, 12+ high; checksum valid for 12/15/18/21/24 only; label "checksum only, balance not checked".
- Telegram: no `/menu`; keep alerts, `/start`, `/stats`.
- No new npm dependencies.

## Review Focus

- **Enormous accounts (10k photos):** gallery paging must stay under ~60 items per request and never read the whole directory for every page.
- **Traversal / odd names:** `../`, spaces, `#`, unicode, HEIC/JPG twins — every file request resolves inside the account root.
- **Stale/partial exports:** a missing `Scan/` or half-written manifest must render empty states, not a 500.
- **Session lifetime:** reload and a second tab keep the login; Disconnect clears it; an expired cookie returns 401 and shows the login.
- **OCR mismatch:** search finds an image by OCR but the grid must show the image thumbnail, with the matched text only as a small caption/preview.
